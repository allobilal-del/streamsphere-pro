# StreamSphere Pro — تطبيق ويب PWA

تطبيق بث مباشر احترافي يعمل في المتصفح مع دعم بث الشاشة الكامل.

## المميزات الكاملة

- 🛡️ **إخفاء ذكي** — إخفاء أجزاء من الشاشة بثلاثة أنواع: نسخ ذكي / ضبابي / أسود
- 🖼️ **شعارات ومائيات** — رفع الشعار وضبط موضعه على البث
- ✏️ **نصوص مباشرة** — إضافة نصوص بألوان وأحجام مخصصة
- 🎙️ **فلاتر الصوت** — صافي / جهوري / راديو / صدى
- 📊 **تحليلات مباشرة** — مشاهدون / ذروة / تفاعل / رسم بياني
- 💬 **شات تفاعلي** — رسائل حية أثناء البث
- 🎬 **تسجيل محلي** — تسجيل البث وتحميله بصيغة WebM
- 🔗 **WHIP/WebRTC** — بث قياسي لخوادم LiveKit / Cloudflare Stream
- 📱 **تحكم عن بعد** — إدارة البث من جهاز آخر بكود اتصال
- 🎭 **6 قوالب جاهزة** — مباراة / ألعاب / درس / مقابلة
- 🎬 **مؤثرات انتقالية** — تلاشي / انزلاق / تكبير / ضبابي / قلب / مسح
- 📦 **PWA** — قابل للتثبيت على أي جهاز من المتصفح

## الرفع على GitHub والنشر التلقائي

### 1. رفع المشروع على GitHub

```bash
git init
git add .
git commit -m "Initial commit: StreamSphere Pro PWA"
git branch -M main
git remote add origin https://github.com/USERNAME/streamsphere-pro.git
git push -u origin main
```

### 2. تفعيل GitHub Pages

- اذهب إلى Repository → **Settings** → **Pages**
- تحت **Source** اختر: **GitHub Actions**
- احفظ الإعدادات

### 3. البناء التلقائي

بمجرد رفع الكود على `main`، سيبدأ GitHub Actions تلقائياً في:
1. تثبيت المكتبات
2. بناء التطبيق
3. نشره على GitHub Pages

التطبيق سيكون متاحاً على:
```
https://USERNAME.github.io/streamsphere-pro/
```

## تشغيل محلي للتطوير

```bash
# تثبيت المكتبات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء للإنتاج
npm run build

# معاينة النسخة المبنية
npm run preview
```

## تثبيت التطبيق كـ PWA على الهاتف

### Android:
1. افتح الرابط في Chrome
2. ستظهر رسالة "إضافة إلى الشاشة الرئيسية"
3. اضغط "تثبيت"

### iOS:
1. افتح الرابط في Safari
2. اضغط زر المشاركة (Share)
3. اختر "إضافة إلى الشاشة الرئيسية"
